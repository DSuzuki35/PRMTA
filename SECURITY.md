# Security

PRMTA 0.2.x is the current development release. The desktop host is loopback-only by default. LAN sharing is an explicit trusted-network feature using HTTP, and its links are bearer credentials. See docs/ARCHITECTURE.md for the security boundaries.

Do not post active studio/output/remote links, private scripts or cloud contents in a public issue. Report a suspected vulnerability using GitHub's private vulnerability reporting feature if available, or contact the repository owner privately. Include the affected version, a minimal synthetic reproduction, impact and operating system. Do not include secrets.

No independent security audit or code-signing certificate is claimed. Third-party dependency audit results are a point-in-time check, not a guarantee.
